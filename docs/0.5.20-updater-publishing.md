## What CohenStore AI actually does

The packaged AI screen is an **on-console, locally saved mod-menu project planner** with a prompt/editor, GTA V Story Mode target `CUSA00419` `v1.56`, presets and themes. It is **not** a connected AI service, an executable mod-menu generator, a compiler or installer. Those capabilities must not be advertised as completed.

## Why publishing is blocked

The PS4 updater currently trusts an Ed25519 public key embedded in the app. The latest signed updater feed is 0.5.17 (version code 517, revision 12). This key **cannot sign** 0.5.20. The matching **private** key is not in the available CohenStore source, developer archives or release material.

The package also has to be uploaded to the exact final GitHub path and its raw download tested before it can be advertised. The GitHub connector available for this chat cannot attach the 45 MB binary release asset directly.

## Safe publication gates

1. Upload the exact verified PKG to the repository at the final URL, without replacing the old 0.5.17 package; check SHA256, byte count, and raw URL delivery.
2. Use the **existing** private Ed25519 signing key in a trusted offline environment to sign revision 13 for version `0.5.20`, code `520`, testing channel, with the final URL, size, hash and existing title/content identity. Never commit or share the private key.
3. Run `tools/validate_0520_release.py --package <path> --release <new-signed-release.json> --previous update/release.json` and normal catalog tests.
4. Update `update/release.json` and `update/manifest.json` only after all gates pass. Preserve the previous signed feed and package for rollback. Do not change the key embedded in deployed clients.
5. Test the **actual on-console** R3/X update path before claiming success. The package is a test release with physical PS4 testing pending.

**Do not** push an unsigned feed or placeholder download URL; deployed clients would reject it and might lose update access.
