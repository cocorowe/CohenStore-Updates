# Install CohenStore 0.5.16

1. In Store Updates, press R3, then X to download 0.5.16.
2. When Update ready appears, close CohenStore.
3. In GoldHEN Package Installer, choose HDD (/data/pkg) and install CohenStore-516.pkg.
4. Reopen, confirm 0.5.16, then press R3 in a browsing tab for the expanded feeds.

L2 outside Mod Menus switches Direct files / All listings; R2 jumps 40 rows. Touchpad shows details and creator/source links. Source-only listings cannot be downloaded inside the store. Square opens the queue; R2 cancels the selected task.

New XML entries in Updates are optional game patches, not full game updates. Read the CUSA/version and setup details before applying. New menu archives/scripts/payloads require their creator's manual setup. Actual PS4 performance and new content setup still need console testing.
